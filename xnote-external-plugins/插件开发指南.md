# X-Note 外部插件开发指南

外部插件是**无构建步骤的裸 JS**（ESM），放在笔记库的 `.xnote-plugins/<插件名>/` 下即可被动态加载，无需重新编译应用。

## 一、最小结构

```
<笔记库>/.xnote-plugins/
└── my-plugin/
    ├── plugin.json     # 清单
    └── main.js         # 入口（可由清单 main 字段指定其他文件名）
```

`plugin.json`：

```json
{
  "id": "my-plugin",
  "name": "我的插件",
  "version": "1.0.0",
  "description": "示例",
  "main": "main.js"
}
```

## 二、插件契约

`main.js` 使用 `export default` 导出插件对象：

```js
export default {
  manifest: { id: 'my-plugin', name: '我的插件', version: '1.0.0', description: '示例' },
  activate(ctx) {
    // 在这里注册命令 / 设置面板
  },
  deactivate(ctx) {
    // 可选：停用清理（命令/面板由宿主按归属自动清理）
  },
}
```

## 三、PluginContext 提供的能力

| 能力 | 说明 |
| ---- | ---- |
| `ctx.storage` | `loadAll / readFile / writeFile / deletePath / getModified / reloadLibrary` 读写笔记库 |
| `ctx.editor` | 当前编辑器：`active / getContent / setContent / getSelection / replaceSelection / insertText / replaceRange / select / focus / onChange` |
| `ctx.http` | `request / postJSON / getJSON`；桌面端在 Rust 侧发请求，不受 WebView CORS 限制 |
| `ctx.settings` | 插件独立设置存储，按插件 id 命名空间隔离，`get(key, def)` / `set(key, value)` |
| `ctx.ui` | `registerCommand` 注册插件菜单项、`registerSettingsPanel` 注册插件中心面板、`showDialog` 弹插件自己的窗口、`closeDialog`、`showToast(text, kind)` 提示 |
| `ctx.log` | 日志输出到控制台 |

### ctx.editor：读写当前笔记

```js
const note = ctx.editor.active()          // { path, title, content } | null
const sel = ctx.editor.getSelection()     // { text, start, end }（无选区时 start === end）

ctx.editor.replaceSelection('新文本')      // 替换选区（无选区则插入到光标处）
ctx.editor.insertText('追加')              // 光标处插入，不删选中内容
ctx.editor.replaceRange(0, 10, 'X')        // 按全文偏移替换任意区间
ctx.editor.setContent('# 整篇重写')        // 整体替换

const off = ctx.editor.onChange(c => console.log('正文长度', c.length))  // 返回取消订阅函数
```

写入与手动输入走同一条链路：自动保存、版本快照、Ctrl+Z 撤销都对插件生效，插件不需要自己写文件。

### ctx.http：请求第三方接口

```js
const res = await ctx.http.postJSON('https://api.deepseek.com/v1/chat/completions',
  { model: 'deepseek-chat', messages: [{ role: 'user', content: '你好' }] },
  { Authorization: 'Bearer ' + key })
if (!res.ok) throw new Error('HTTP ' + res.status + '：' + res.text)
const text = res.data.choices[0].message.content
```

桌面端由 Rust 侧发出请求，因此 OpenAI 兼容接口这类**不返回 CORS 头**的服务也能直接调用；
浏览器预览模式退回 `fetch`，会被同源策略限制（这就是为什么 AI 类插件建议在桌面端使用）。

### ctx.ui.showDialog：插件自己的窗口

```js
ctx.ui.showDialog({
  id: 'my-plugin',
  title: '我的工具',
  subtitle: '可选副标题',
  width: 720,
  render: () => window.XNoteReact.createElement(Panel, { ctx }),
})
```

宿主只负责外壳（标题 / 宽度 / 关闭 / Esc / 滚动），面板内容与状态由插件自己管理；`ctx.ui.closeDialog()` 可主动关闭。

## 四、注册命令与设置面板

```js
activate(ctx) {
  ctx.ui.registerCommand({
    id: 'my-plugin.hello',
    title: '我的插件',
    run: () => ctx.ui.showToast('Hello!', 'success'),
  })

  ctx.ui.registerSettingsPanel({
    id: 'my-plugin',
    title: '我的插件',
    render: () => window.XNoteReact.createElement(Panel, { getConfig, saveConfig }),
  })
}
```

## 五、在外部插件中构建设置面板

外部插件不能 `import 'react'`；宿主把同一个 React 实例挂在 `window.XNoteReact` 上，
用 `createElement` + hooks 即可渲染交互面板：

```js
function Panel({ getConfig, saveConfig }) {
  const { createElement: h, useState } = window.XNoteReact
  const [cfg, setCfg] = useState(getConfig())
  return h('input', { value: cfg.token, onChange: (e) => saveConfig({ ...cfg, token: e.target.value }) })
}
```

## 六、测试方法

1. 把插件目录复制到笔记库 `.xnote-plugins/`
2. X-Note「设置 → 外部插件 → 重载插件目录」
3. 顶栏出现命令按钮；「设置 → 插件」区出现设置面板
4. 浏览器预览模式下，插件目录由 localStorage（`xnote:external-plugins`）模拟，首次运行会自动安装 hello-world 演示插件，可直接在控制台修改该键做实验

## 七、FAQ

**插件加载失败？** 「设置 → 外部插件」会显示每个插件的加载状态与错误信息（缺清单 / 入口抛错 / 形状不符）；单个插件损坏不影响其他插件。

**如何发布插件？** 把插件目录打包发给别人，复制进 `.xnote-plugins/` 即可。发布前请自查不包含恶意代码——外部插件以应用的完整权限执行任意本地代码。

**契约类型定义？** 以仓库 `src/plugins/types.ts` 为准。
