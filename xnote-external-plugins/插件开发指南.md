# X-Note 外部插件开发指南

外部插件是**无构建步骤的裸 JS**（ESM），放在笔记库的 `.xnote-plugins/<插件名>/` 下即可被动态加载，无需重新编译应用。

## 一、最小结构

```
<笔记库>/.xnote-plugins/
└── my-plugin/
    ├── plugin.json     # 清单
    └── main.js         # 入口（可由清单 main 字段指定其他文件名）
```

`plugin.json`：

```json
{
  "id": "my-plugin",
  "name": "我的插件",
  "version": "1.0.0",
  "description": "示例",
  "main": "main.js"
}
```

## 二、插件契约

`main.js` 使用 `export default` 导出插件对象：

```js
export default {
  manifest: { id: 'my-plugin', name: '我的插件', version: '1.0.0', description: '示例' },
  activate(ctx) {
    // 在这里注册命令 / 设置面板
  },
  deactivate(ctx) {
    // 可选：停用清理（命令/面板由宿主按归属自动清理）
  },
}
```

## 三、PluginContext 四类能力

| 能力 | 说明 |
| ---- | ---- |
| `ctx.storage` | `loadAll / readFile / writeFile / deletePath / getModified / reloadLibrary` 读写笔记库 |
| `ctx.settings` | 插件独立设置存储，按插件 id 命名空间隔离，`get(key, def)` / `set(key, value)` |
| `ctx.ui` | `registerCommand` 注册顶栏命令、`registerSettingsPanel` 注册设置面板、`showToast(text, kind)` 提示 |
| `ctx.log` | 日志输出到控制台 |

## 四、注册命令与设置面板

```js
activate(ctx) {
  ctx.ui.registerCommand({
    id: 'my-plugin.hello',
    title: '我的插件',
    run: () => ctx.ui.showToast('Hello!', 'success'),
  })

  ctx.ui.registerSettingsPanel({
    id: 'my-plugin',
    title: '我的插件',
    render: () => window.XNoteReact.createElement(Panel, { getConfig, saveConfig }),
  })
}
```

## 五、在外部插件中构建设置面板

外部插件不能 `import 'react'`；宿主把同一个 React 实例挂在 `window.XNoteReact` 上，
用 `createElement` + hooks 即可渲染交互面板：

```js
function Panel({ getConfig, saveConfig }) {
  const { createElement: h, useState } = window.XNoteReact
  const [cfg, setCfg] = useState(getConfig())
  return h('input', { value: cfg.token, onChange: (e) => saveConfig({ ...cfg, token: e.target.value }) })
}
```

## 六、测试方法

1. 把插件目录复制到笔记库 `.xnote-plugins/`
2. X-Note「设置 → 外部插件 → 重载插件目录」
3. 顶栏出现命令按钮；「设置 → 插件」区出现设置面板
4. 浏览器预览模式下，插件目录由 localStorage（`xnote:external-plugins`）模拟，首次运行会自动安装 hello-world 演示插件，可直接在控制台修改该键做实验

## 七、FAQ

**插件加载失败？** 「设置 → 外部插件」会显示每个插件的加载状态与错误信息（缺清单 / 入口抛错 / 形状不符）；单个插件损坏不影响其他插件。

**如何发布插件？** 把插件目录打包发给别人，复制进 `.xnote-plugins/` 即可。发布前请自查不包含恶意代码——外部插件以应用的完整权限执行任意本地代码。

**契约类型定义？** 以仓库 `src/plugins/types.ts` 为准。
